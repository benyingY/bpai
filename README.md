# BPAI 机器学习平台

BPAI 面向共享算力的算法团队和 AI agent，覆盖开发空间、训练、推理、AI 资产、调度、GPU 稳定性、资源看板与账单。仓库当前处于产品与架构设计阶段。

| 阅读入口 | 适合了解的问题 |
| --- | --- |
| [产品设计](产品设计.md) | 用户如何从开发进入训练和上线？人和 agent 如何接手同一项工作？ |
| [系统架构](系统架构.md) | 控制面、计算集群、资产存储和计量如何协作？可靠性按什么标准验收？ |
| [模块实现设计](模块实现设计.md) | 各模块用什么组件执行？任务如何选择集群？数据和可写工作卷怎样跨集群访问或迁移？ |
