# BPAI 机器学习平台

BPAI 面向共享算力的算法团队和 AI agent，覆盖开发空间、训练、推理、AI 资产、调度、GPU 稳定性、资源看板与账单。仓库当前处于产品与架构设计阶段。

| 阅读入口 | 适合了解的问题 |
| --- | --- |
| [产品设计](product-design.md) | 用户如何从开发进入训练和上线？人和 agent 如何接手同一项工作？ |
| [系统架构](system-architecture.md) | 控制面、计算集群、资产存储和计量如何协作？可靠性按什么标准验收？ |
| [模块实现设计](module-design.md) | Volcano 队列如何确定训练集群？每个 worker 如何选 GPU 套餐，共享输入输出及 OSS 数据如何访问？ |

## Language

Documentation and direct conversations with the user may use Chinese. Use English for everything else, including file and directory names, code and comments, configuration, API fields, UI and CLI text, logs, and error messages. Use English for branch names, commit messages, issues, and pull requests.
